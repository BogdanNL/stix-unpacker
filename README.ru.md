# stix-unpacker

[English version](README.md)

Консольная утилита на Rust для распаковки однотомных и многотомных архивов
InstallShield 3.x / The Stirling Compressor. Определяет архивы по сигнатуре
заголовка, группирует пронумерованные тома по базовому имени и восстанавливает
файлы, данные которых разделены между томами. Также распознаёт отдельные архивы,
включая `.z` и `.lib`.

## Использование

`INPUT` — папка с архивами или путь к первому тому; `OUTPUT` — папка назначения.
Вместо этих обозначений укажите свои пути.

```sh
stix-unpacker INPUT OUTPUT
stix-unpacker --std INPUT OUTPUT
stix-unpacker --test INPUT
stix-unpacker --list INPUT
```

Запуск без аргументов выводит версию и справку. Код завершения — 0 при успехе
и 1 при ошибке.

| Ключ | Описание |
| --- | --- |
| `-x`, `--extract` | Распаковать файлы; операция по умолчанию. Требует `INPUT OUTPUT`. |
| `-t`, `--test` | Распаковать и проверить архивы без записи файлов. Требует `INPUT`. |
| `-l`, `--list` | Показать группы архивов, тома, пути файлов, размеры и даты в формате DOS. Требует `INPUT`. |
| `--std`, `--setup` | Выбрать только архивы, имена которых начинаются с `std`, без учёта регистра, и объединить их содержимое в `OUTPUT`. Также работает с `--test` и `--list`. |
| `--overwrite` | Разрешить замену существующих обычных файлов в папке назначения. |
| `--encoding E` | Кодировка имён файлов: `cp1251` (по умолчанию), `cp437` или `utf-8`. Содержимое файлов не перекодируется. |
| `-h`, `--help` | Показать версию и справку. |
| `-V`, `--version` | Показать только версию. |
| `--` | Завершить разбор ключей, чтобы далее можно было указать пути, начинающиеся с `-`. |

Входная папка сканируется рекурсивно. Расположение томов и номера физических
дисков не определяют порядок их чтения. По умолчанию каждый найденный архив
распаковывается в отдельную подпапку назначения. Если указан конкретный файл,
обрабатывается только его архив, а содержимое распаковывается прямо в `OUTPUT`.
Пронумерованные тома ищутся рядом, в том числе в соседних папках дисков, если
первый том находится в папке вида `DISKN`.

С ключом `--std` или `--setup` выбранные архивы распаковываются в общую папку.
Имена каталогов объединяются без учёта регистра: `EXTFORMS` и `extforms`
превращаются в `ExtForms`, в том числе во вложенных путях. Для остальных
каталогов сохраняется первое встретившееся написание. Существующие каталоги
назначения не переименовываются. Конфликты путей файлов между архивами
выявляются до распаковки и приводят к ошибке даже с ключом `--overwrite`.

Отсутствующие или несовместимые тома приводят к ошибке. Каждый выходной файл
появляется под итоговым именем только после успешной распаковки. Режим `--test`
проверяет структуру, маркеры конца сжатых потоков и размеры; сохранённые
контрольные суммы отдельных файлов не проверяются. Даты файлов отображаются,
но не восстанавливаются. Самораспаковывающиеся EXE-оболочки, зашифрованные архивы
и более поздние форматы InstallShield CAB не поддерживаются.

## Сторонние исходники

Структура архивов изучена по **STIX Вайта Каннегизера (Veit Kannegieser)**,
включая исходники на Pascal и адаптацию для Linux. Парсер архивов представляет
собой новую реализацию на Rust.

- [Оригинальные исходники STIX: зеркало ZIP](https://ecsoft2.org/system/files/repository/stix_src.zip).
- [Оригинальные исходники STIX: авторский архив ARJ](https://kannegieser.net/veit/quelle/stix_src.arj).
- [Порт STIX для Linux](https://github.com/DeclanHoare/stix).

Декодер DCL в `src/explode.rs` — изменённая реализация на Rust на основе
[blast 1.3 Марка Адлера (Mark Adler)](https://github.com/madler/zlib/tree/master/contrib/blast),
включая канонические таблицы Хаффмана и алгоритм декодирования. Это не оригинальный
дистрибутив blast. См. [лицензию blast](https://github.com/madler/zlib/blob/master/contrib/blast/blast.h#L1-L19).
